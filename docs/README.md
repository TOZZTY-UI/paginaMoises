# Guía del proyecto

Esta carpeta explica la estructura de `pagina_Moises`, qué contiene cada archivo y qué podría agregarse. Los ejemplos son orientativos: no indican que las funcionalidades ya estén implementadas.

- [Estructura y ejemplos del proyecto](./estructura.md)
- [Organización de los estilos](./estilos/README.md)

El proyecto usa Astro, TypeScript y Tailwind CSS. Para instalar dependencias se usa `npm install`; para iniciar el desarrollo, `npm run dev`; y para generar la versión de producción, `npm run build`.
